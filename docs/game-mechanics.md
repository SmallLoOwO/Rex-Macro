# REX 遊戲機制筆記（給自動化用）

實機觀察到、會影響偵測設計的重點。**寫給「未來的我們」記住**。

## 通則（很重要）

- **背景永遠會變**：畫面背景隨玩家所在區域改變，整片可能被染成紅/藍等。
  → 任何 UI 偵測**只能比形狀/邊緣（color-invariant）、並裁緊**；顏色與背景完全不可靠。
- **工具使用後，右下角會出現「冷卻圖案」**，和 boost 瓶子在**同一條效果/冷卻列**，而且 **buff/冷卻會疊加 → 位置會位移，但都在同一區域內**。
  → 偵測要在**整條效果列裡搜尋**該圖示（不是固定一點）；用「圖示在不在」判斷工具好了沒，不必盲目計時。

## 各工具

### D5 — Boost（加成）✅ 已實作並驗證
- 用法：D5 + 左鍵點畫面 → 生效，右下角出現**青色瓶子 + 倒數數字**。
- 數字會變、位置會因疊加而移。
- 邏輯：**瓶子消失 = 效果結束 → 重上**（D5+點擊 → 回 D1+按住 W+左鍵）。
- 偵測：`boost_active.png` 在 `boost_indicator_region` 內做邊緣+多尺度比對；找不到且過冷卻 → 重上。
  實測此模板對「數字變化(54/50…)、堆疊位移」都偵測得到，偵測穩定。
- **重上的關鍵（實測 2026-06-26）**：挖礦時是**按住左鍵**的，重上要先**確實放開左鍵→沉澱一下→再點擊**，
  否則殘留的「按住」會和放置點擊衝突、被遊戲吃掉，boost 放不出來（log 會狂洗「boost 消失→重上」）。
  已在 `miner.use_boost`（`ic.settle()` + `mouse_click(hold=0.08)`）處理。

### D4 — Activity（控制活動）
- **左鍵 = 加強目前事件**：頂部文字**不變**，但左上聊天框會顯示（例：
  "X has increased the event time by 50%."、"X has boosted the current event ore by 10%!"）。
  可能增加活動長度或活動礦出現機率。
- **右鍵 = 刷新事件**：頂部文字**會被替換**，聊天框也顯示（例："X has replaced the ongoing event."）。
  少數情況會刷出同一個活動。
- **冷卻圖示（實測確認 2026-06-26）**：使用後右下角效果列出現一顆 **「Used」按鈕**（掃描瓶圖示+白字 Used，
  和 boost 瓶子同一列、會堆疊位移）。**冷卻好時這顆 Used 按鈕會整個消失**（同 boost 瓶子邏輯）。
  → 偵測 `d4_cooldown.png`（那顆 Used 按鈕）在 `boost_indicator_region` 內：**找得到 = 冷卻中、別按；找不到 = ready、就按**。
- **冷卻很長**：實測 114 秒不動它仍顯示 Used（正常冷卻 >2 分）。但 D4 會 lucky「**再來一次**」直接退冷卻、可馬上再滾，
  所以靠「冷卻圖示消失」偵測才抓得到那個瞬間；舊的固定 30s 定時會錯過、且大多時候按了是 no-op。
- 已實作：`miner.cooldown_ready` + `main._activity_ready`（config `activity_cooldown_*`）。缺模板時退回定時後備。

### D2 — Scan（掃描）
- 用法：使用後若附近有稀有礦，會出現它的**外框（= 我們的 marker）**；左下角顯示 **"Local" 已使用**。
- 採集流程（偵測到 chill 後）已會按 D2。是否要**定時主動掃描**待定。
- 使用後右下角同樣有冷卻圖案。

### Z — Cybernetium Radar（cave，特殊情況才用）
官方能力說明：
- **Z**：掃描 250 格半徑內特殊洞穴的方塊。冷卻 30 秒（掃完最後一個洞後起算）。
- **左鍵**：自動開採 100 格內 Uncommon–Mythic 礦；追蹤 250 格內 Surreal+ 礦。冷卻 30 秒。
- **右鍵**：全域追蹤礦場內所有 Exotic+ 礦。冷卻 25 秒；追蹤存活 30 秒。
- → 特殊用途，預設**先擱置**。
